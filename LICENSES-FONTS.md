# Font licenses

Nota Limonada Light embeds three typefaces directly in `theme.css` (base64-encoded `woff2`,
Latin subset). All three are licensed under the **SIL Open Font License, Version 1.1**, which
explicitly permits embedding, bundling, and redistributing the fonts as part of another software
package — see https://scripts.sil.org/OFL for the full license text.

## Libre Franklin

- Designer: Impallari Type, in collaboration with Pablo Impallari and Rodrigo Fuenzalida
- Source: https://fonts.google.com/specimen/Libre+Franklin
- License: SIL Open Font License, Version 1.1

## Libre Baskerville

- Designer: Pablo Impallari
- Source: https://fonts.google.com/specimen/Libre+Baskerville
- License: SIL Open Font License, Version 1.1

## Fira Mono

- Designer: Carrois Type Design (originally commissioned by Mozilla)
- Source: https://fonts.google.com/specimen/Fira+Mono
- License: SIL Open Font License, Version 1.1
